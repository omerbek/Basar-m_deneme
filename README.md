# Basar-m_deneme

GitHub işlemlerini ve entegrasyonlarını denemek için kullanılan test deposu.

## Doğrulanan işlemler

- Ayrı bir dal oluşturma ve dosya commit etme
- Issue açma ve kapatma

## Pull request ile değişiklik yapma

1. Güncel `main` dalından yeni bir dal oluştur.
2. Değişikliği bu dala commit et.
3. Hedef dalı `main` olan bir pull request aç.
4. Değişiklikleri ve varsa otomatik kontrolleri kontrol et.
5. Uygun değişikliği birleştir ve sonucu `main` üzerinde doğrula.

Denemelerde parola, erişim anahtarı veya kişisel veri kullanma.
